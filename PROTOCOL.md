# Sentinel native bridge v1

UI code calls `window.Sentinel.call(method, params)`. The shared `web/backend.js` performs refresh/report aggregation and sends native commands as `{id: string, method: string, params: object}` using `window.chrome.webview.postMessage(request)` on Windows or `window.SentinelNative.postMessage(JSON.stringify(request))` on Android. Native replies by evaluating `window.sentinelReceive({id, result})` or `{id,error: "safe message"}`. Windows posts the response to chrome.webview; UI handles both. Never serialize apiKey into response, log, errors, exports or snapshots.

Native transport commands are `getState`, `saveConnection`, `removeConnection`, `saveSettings`, `scanLocal`, `saveSnapshots`, `request`, `getOllamaUsage`, `copyKey`, and `openExternal`. `refresh` and `benchmarkOllama` are shared-domain commands, not native commands. `request` takes a saved connection id, an allowlisted path and optional fixed benchmark body; native code chooses the host and attaches the saved key. `saveSnapshots` persists sanitized report data. `getOllamaUsage` returns the Windows local proxy's token-only ledger for the default local server, or `{available:false}` when unavailable. `copyKey` copies natively without returning the secret to JavaScript. `saveSettings` also accepts optional `ollamaMeter:boolean` on Windows to enable/disable the local forwarding server at 127.0.0.1:11435.

Methods:
- `getState`: returns state below, ready from disk. Does not run network refresh.
- `refresh`: refreshes all configured connections + native local sessions on Windows, returns complete state. Individual errors captured in each snapshot, not entire request. UI serializes refresh calls. Initial refresh after load and every setting refreshSeconds (default 300). Maximum days 30.
- `saveConnection`: params `{id?: string,providerId: string,name: string,adapter: string,apiKey?: string,baseUrl?: string,manualBalance?: number|null}`. New id GUID; key empty/omitted retains previous key. Allowed adapters openai,anthropic,openrouter,deepseek,ollama,manual. Allowed names/ids bounded to 120. If provider id custom*, URL for external link lives frontend only unless safely stored. Fixed official cloud endpoints; baseUrl only for ollama. Returns complete state. Manual balance is expressly user-entered USD, snapshot source manual.
- `removeConnection`: `{id}` removes connection, snapshot and key, returns state.
- `saveSettings`: `{refreshSeconds: 60|300|900|0}`, returns state. 0 disables automatic refresh.
- `benchmarkOllama`: `{id,model}` runs /api/generate with fixed short prompt, stream:false and num_predict:32. Explicit user action only. Tracks counts from real response, returns state; snapshot tokens cumulative measured by Sentinel, never claims systemwide inference total.
- `openExternal`: `{url}` opens HTTPS link (or http loopback only) via OS default browser; reject other schemes; returns `{ok:true}`.

State: `{platform:"windows"|"android",version:"1.0.0",connections: Connection[],snapshots: {[connectionId]: Snapshot},localUsage: {codex: LocalUsage,claude: LocalUsage},settings:{refreshSeconds:300},refreshedAt?: ISO}`.

Connection public shape: `{id,providerId,name,adapter,baseUrl?,hasKey:boolean,keyHint:string,manualBalance?:number|null}`. apiKey only encrypted native storage. Do not reveal entire key; hint e.g. "••••abcd". No key reveal operation.

Snapshot: `{status:"ok"|"error"|"unconfigured"|"manual"|"offline",checkedAt:ISO,source:string,detail:string,balanceUsd?:number|null,usageUsd?:number|null,tokens?:number|null,inputTokens?:number|null,outputTokens?:number|null,cachedTokens?:number|null,requests?:number|null,models?:[{name:string,size?:number,loaded?:boolean}],history?:[{date:"YYYY-MM-DD",tokens?:number,usageUsd?:number}],latencyMs?:number}`. Use missing/null for unknown; never zero to represent unknown. UTC last 30 days with dates in UI converted locally. Only add numbers truly observed. Cloud costs cover last 30d; clarify costs vs remaining wallet and currency conversion not provided. Provider errors have no balance/token placeholders.

LocalUsage: `{status:"ok"|"unavailable"|"error",source:string,detail:string,inputTokens?:number,outputTokens?:number,cachedTokens?:number,tokens?:number,requests?:number,sessions?:number,history?:[{date:string,tokens:number}],checkedAt?:ISO,rateLimits?:[{name:string,usedPercent:number,resetsAt?:ISO}]}`. Local sessions cover last 30d; counts represent local observed tokens, not subscription billing. Windows auto-scans only token fields in ~/.codex/sessions, ~/.codex/archived_sessions, ~/.claude/projects; do not read auth files. Android unavailable means connect cloud admin APIs for cloud usage, no inaccessible desktop logs claim. Ollama needs baseUrl localhost Windows or LAN Android; private subnet validation and no redirect key leaks.

Frontend static assets in ../web/index.html, app.js, styles.css, providers.js; Android packages into assets/web/ and load file:///android_asset/web/index.html. Windows embeds resources and serves via virtual host https://sentinel.local/ (no open network port), native main app built .NET8 WinForms WebView2.


## Sentinel 1.1 additions

Public state adds bounded activityLog, sanitized discoveries and settings.theme. Local usage adds up to 500 token-only records with timestamps and input/output/cache fields. saveConnection supports accountLabel, walletGroup and manualUpdatedAt provenance. clearKey and clearActivityLog provide deletion controls. Windows importLocalConnections discovers credentials only for recognized hosts; scanConnections is read-only. signInOpenRouter implements native PKCE; Windows uses a loopback callback and cancellation, Android returns pendingAuthorization for headless code entry and finishSignInOpenRouter. No password, browser cookie or refresh token is imported. New AgentRouter compatibility fields are API-key allowance and an unconverted reportedUsageRaw counter; neither is an account-wallet amount.
